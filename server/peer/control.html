A second way to the table.

Run the app on both computers. Choose who hosts the puzzle, use the same private connection key, and connect. The host keeps the saved game. Your browser still uses ordinary HTTP and Socket.IO through the peer tunnel.

Share this key privately. Both players must enter the same key. It authenticates and encrypts the direct tunnel. It is kept in memory, never saved to disk.

Start both sides. Probes repeat every 250 ms until the authenticated handshake succeeds; keep-alives run every 2 seconds. Use the peer’s externally mapped UDP port if their router changes it. In “Try both”, this address is optional.

Both players use the same reachable server. It exchanges encrypted connection information automatically; you don’t enter peer IPs or ICE candidates. A localhost URL works only when both browsers can reach that computer. Keep this Connection options tab open for WebRTC.

STUN and optional TURN settings

ICE tests available paths. TURN is a relay fallback when no direct route succeeds. No TURN service is bundled or configured for you.
